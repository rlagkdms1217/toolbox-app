내 파일은 어디로 가나요?

툴박스 도구는 세 가지로 나뉘어요. 도구 화면에도 "기기에서 처리"·"기기 AI" 또는 "AI" 표시가 있어요.

내 기기 안에서만 파일이 밖으로 나가지 않아요

파일을 서버로 보내지 않고, 이 기기(브라우저·앱) 안에서 처리해요. 툴박스 서버도 파일을 볼 수 없어요. 인터넷을 끊어도 대부분 돼요.

"기기 AI" 도구는 처음 한 번 AI 모델 파일을 받기만 하고, 사진은 올리지 않아요. PC용 고급 모델(누끼·지우기·얼굴 복원)은 용량이 커서 공개 저장소(jsDelivr·GitHub)에서 받는데, 이때도 모델 파일만 내려받고 받은 파일이 원본과 같은지 지문(SHA-256)으로 확인해요.

누를 때만 AI로 기본은 기기 안, AI 버튼을 누를 때만 보내요

기본 기능은 기기 안에서 처리해요. "AI로 찾기"처럼 AI 버튼을 직접 누를 때만 그 내용을 AI 서버로 보내요.

  • 개인정보 가리기 — "AI로 찾기" (얼굴만 찾기는 기기 안에서)
  • 문서 스캔 — "글자 추출"
  • 텍스트 비교 — "AI로 바뀐 점 정리"

AI 서버로 보내요 결과를 만들려면 외부 AI가 내용을 읽어야 해요

넣은 글·파일을 결과를 만들기 위해 외부 AI(Google 등)로 보내요. 툴박스 서버는 전달만 하고 입력을 저장하지 않아요. 새로고침해도 결과를 다시 받을 수 있게 AI가 만든 답만 약 1시간 보관한 뒤 자동으로 지워요.

어느 회사로 가는지, 그 회사가 얼마나 보관하는지는 개인정보처리방침 4번에 있어요.

보안을 위해 하는 일

  • 모든 연결은 암호화(HTTPS)돼요. 암호화되지 않은 주소로 들어와도 자동으로 암호화 연결로 바꿔요.
  • 비밀번호를 받지 않아요. 로그인은 구글(선택)이 대신 확인해 주고, 툴박스는 비밀번호를 볼 수 없어요.
  • 입력한 글·파일을 서버에 저장하지 않아요. AI 도구도 전달만 해요.
  • 회의 녹음 원본은 내 기기에만 있어요. 로그인해서 동기화를 켜도 녹음 파일은 올라가지 않아요.
  • 접속 IP는 원래 값을 저장하지 않고 되돌릴 수 없게 바꾼 값만 남겨요(사용량 한도 계산용). 파일 이름·내용은 기록하지 않아요.
  • 로그인 안 하면 기록은 이 기기에만 남아요. 로그인해도 설정 → "이 기기에만 저장"을 켜면 서버에 올리지 않고, 이미 올라간 것도 지워요.
  • 광고·판매 없음. 개인정보를 팔거나 광고에 쓰지 않아요.
  • 다른 사이트가 툴박스 화면을 몰래 끼워 넣거나(클릭재킹), 파일 형식을 속이지 못하게 막는 브라우저 보안 설정을 켜 두었어요.

자주 묻는 질문

회사 문서를 넣어도 되나요?

"내 기기 안에서만" 도구(PDF·변환·이미지 편집 등)는 파일이 회사 밖으로 나가지 않으니 비교적 안전해요. "AI 서버로 보내요" 도구는 외부 AI가 내용을 읽으니, 회사 보안 규정을 먼저 확인하고 기밀·고객 개인정보는 빼고 넣어 주세요.

AI가 내 내용을 학습하나요?

베타 기간에는 일부 AI 처리에 Google의 무료 이용 등급을 써서, Google이 서비스 개선에 이용할 수 있어요. 민감한 내용은 넣지 마세요.Google 유료 이용 등급을 써서 입력 내용을 학습에 쓰지 않아요. 남용 방지를 위해 제한된 기간만 기록돼요. 자세한 내용은 개인정보처리방침에 있어요.

PC와 폰에서 결과가 조금 달라요

누끼·지우기·화질 개선은 기기 안에서 AI를 돌려서, 기기 성능에 맞는 모델을 골라 써요. 그래픽카드가 있는 PC와 앱은 더 크고 정교한 모델을, 폰 웹은 가벼운 모델을 써요. 어떤 모델로 처리했는지는 결과 아래에 적혀 있어요. 사진을 서버로 보내지 않는 대신 생기는 차이예요.

이상한 파일을 열어도 안전한가요?

다른 사람이 보낸 엑셀·CSV·워드·마크다운·HTML 파일을 열어도, 그 안에 숨겨진 코드는 실행되지 않고 글자로만 보여요. 파일 이름이나 AI가 돌려준 답에 코드가 섞여 있어도 마찬가지예요. 이런 경우를 자동 시험으로 계속 확인해요.

앱은 뭐가 다른가요?

앱도 같은 원칙이에요. "기기에서 처리" 도구는 폰의 AI 엔진으로 돌아가고, 인터넷 없이도 돼요. 결과 저장은 폰의 갤러리·다운로드 폴더(아이폰은 공유 창)로 바로 가요.

지운 기록은 정말 지워지나요?

기기에 있는 기록은 바로 지워져요. 계정에 동기화된 기록은 지우는 순간 서버에서도 지워지고, 탈퇴하면 계정 정보와 기록이 즉시 삭제돼요. 보관 기간 전체는 개인정보처리방침 3번에 있어요.

보안 문제를 발견했어요
