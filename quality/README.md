# 모델 품질 확인

| 무엇 | 어떻게 | 언제 |
|---|---|---|
| 압축(8비트) 모델 = 원본(32비트)? | `python3 -I quality/q8_check.py` — 배포하는 조각 파일을 풀어 원본과 같은 사진으로 돌려 비교 | 새 모델을 넣거나 압축 방식을 바꿀 때 |
| 도구 결과가 전과 같은가? | 웹 시험 `t161_golden.mjs` — 누끼 3종·지우기·화질 개선 2종을 저장해 둔 기준 결과와 비교 | 코드를 고칠 때마다 (전체 시험에 포함) |
| 악성 입력에 안전한가? | 웹 시험 `t160_xss_a/b/c.mjs` — 악성 파일 이름·내용·AI 답 83개 흐름 | 코드를 고칠 때마다 |
